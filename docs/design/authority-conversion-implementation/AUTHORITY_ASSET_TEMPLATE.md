# Authority Asset Template

**Brand:** Existing Octus system only — no sub-brand.

## Grammar

- `OctusSymbolMarker` in dark hero  
- Editorial numerals (`01`…) for chapters  
- `OctusEditorialDivider` between sections  
- Navy dark hero + light body  
- High-contrast Unigeo headings / Inter body  
- `.authority-asset` + print CSS (browser Print → PDF)

## Page shell

1. Dark hero: label · H1 · one-line purpose · print hint  
2. Body chapters with numerals  
3. Notice / guardrails where educational  
4. CTA row: Discuss · Assess (if relevant) · Email — `print:hidden`

## Future types using same shell

Regulatory Signals · Guides · Checklists · Executive Briefings · Webinar one-pagers

## Not allowed

New logos · SaaS document templates · fake PDF generators · stock icon farms
