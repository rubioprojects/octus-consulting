| Status | `REQUIRES_RUBIO_REVIEW` |
| Date | 2026-08-02 |
| Format | 1 page EN (default) |

## Structure

1. **Title** — public area or priority service name  
2. **One sentence** — from catalog  
3. **Who it is for** — client profile (3 bullets max)  
4. **What we do** — 4–6 concrete bullets  
5. **Typical deliverables** — 3–5 items  
6. **Not included** — 2–4 exclusions  
7. **Related areas** — cross-sell line  
8. **Contact** — commercial intake  
9. **Footer** — “No outcome guarantees; gov fees separate” (short)

## Forbidden on one-pager

Prices · partner brands · unverified metrics · case logos without approval
