| Offshore framing | “Offshore Structuring” page | Reposition language away from tax haven shop |
| Absolute claims | “zero critical findings” mandate | Keep only if evidence retained internally |
| Startup / hype | Mostly avoided | Continue ban on world-class / transformation |
